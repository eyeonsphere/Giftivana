# Decisions log

Short, dated records of choices that shape the codebase. Add to the top.

## 2026-11-07 — Stage 2

- **Next.js 16 instead of 15.** 16 is the current stable line; `create-next-app` scaffolds it with Cache Components on. Consequence: anything reading cookies/params/searchParams must sit in `<Suspense>`; `middleware.ts` is `proxy.ts` in Stage 3.
- **Self-hosted fonts via Fontsource** rather than `next/font/google`, so builds never depend on network access.
- **Cart via `useSyncExternalStore`** over localStorage. Server and first client render agree (empty); the real cart appears after hydration. No effect-driven `setState` (React 19 lint rule).
- **Destination in an httpOnly cookie** written by a Server Action that validates the slug against the catalog. Pages filter server-side; no client-side availability logic.
- **Placeholder SVG art** generated by `scripts/generate-demo-images.mjs`, labelled "demo placeholder" in the image itself. No stock or AI-generated "photos" that could be mistaken for real products.
- **Supporting-page copy is plain English in the page files**, while chrome and reusable strings go through `messages/en.json`. When Arabic is added, long-form pages become per-locale MDX/markdown rather than JSON keys.
- **`react/no-unescaped-entities` disabled.** Apostrophes in UI copy are correct English.
